Automatic Off-Device Backup
Every time you save or delete an entry, your full log is pushed to a private data file in your GitHub repo — off your phone, so a lost or wiped device can't take it with it. Restoring reads that file back automatically, no token needed.
  1. Go to github.com/settings/tokens?type=beta in Safari
  2. Generate new token → name it "Captains Log Backup"
  3. Repository access → Only select repositories → choose Captains-Log
  4. Permissions → Contents: Read and write
  5. Generate, copy the token, paste it below
